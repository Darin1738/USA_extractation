# ASSET SOURCES — INDEX

This is the index for everything in `assets/`. It points to the detailed record for each asset type.

| Asset type | Folder | Detailed source record |
|---|---|---|
| Fonts | `assets/fonts/` | `assets/fonts/SOURCES.md` (SIL OFL 1.1; licence text in `OFL.txt`) |
| Original symbols | `assets/symbols/` | `assets/symbols/SOURCES.md` (original vector artwork, generated by `scripts/make_symbols.py`) |
| External imagery | `assets/external/` | `assets/external/SOURCES.md` (currently none) |
| Board photographs | `../media/` | `MEDIA_MANIFEST.md` at the project root of this folder |
| Panel claims / citations | — | `BIBLIOGRAPHY.md` and `VERIFY.md` at the project root of this folder |

**Rule:** every raster image must have a filename-keyed source/credit row. External images belong in `assets/external/`; project photographs belong in `../media/` and are logged in `MEDIA_MANIFEST.md`.

**No AI-generated imagery** is used anywhere on the board.
