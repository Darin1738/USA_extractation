# MEDIA MANIFEST
**Board:** *The Name Changes. The Function Does Not.* — Group 4, HIST 350  
**Version:** v1, 21 Oct 2026  
**Media root:** `../media/` (sibling of this `infographic/` folder)

Every photograph that appears on the board is listed below with the exact filename, where it appears, the caption used on the board, and the credit/verification status. Filenames are the key: if a file is renamed, update this table and the `images:` entry in `scripts/build_board.py`.

**Status key**

| Status | Meaning |
|---|---|
| **VERIFIED** | Source/credit is confirmed in the board copy, file metadata or a stable publication. |
| **VERIFY** | The image is used, but the exact source/credit still needs to be confirmed before public display or submission. |
| **RIGHTS CHECK** | Credit is known, but permission/reuse status is not. Do not publish beyond classroom fair use without clearing it. |
| **DO NOT USE** | Rights or content problem; not on the board. |

> The board's P6 deliberately omits graphic lynching photographs. The record is carried by text, the segregation sign and the EJI marker. This follows the group's stated rule: no sensational reproduction of racial violence.

## External imagery

**None.** All board photographs come from `../media/`. If the group adds an outside image:

1. Save it in `assets/external/` with a descriptive filename.
2. Add a row to `assets/external/SOURCES.md` with filename, URL, author, licence/permission, access date, and any cropping/colour changes.
3. Add it to the panel data in `scripts/build_board.py` and to this manifest.
4. Do not hotlink, and do not use an image whose licence you cannot state.

---

## Rebuild note

The board's media references are relative to `infographic/index.html` as `../media/<file>`. If you move `index.html` without the media folder, the interactive images break (the PNG/PDF still work). For a portable interactive package, keep this structure:

```
new/
├── media/
└── infographic/
    ├── index.html
    ├── assets/
    ├── out/
    └── scripts/
```
